## ✨ Features

- 🕹️ **One-Key Control** - Press `SPACE` to invert gravity (UP ↔ DOWN)
- 🌌 **Space Aesthetic** - Dark neon environment with a starfield background and glowing platform obstacles
- 🚀 **Quick Launch** - Jump straight into a run with the **PLAY NOW** button
- 📈 **Live Score Tracking** - Real-time score and personal best shown during gameplay
- 🏆 **Global Leaderboard** - Compete with other players, with top "Elite Jumpers" shown on the home page
- 👤 **Player Accounts** - Register and log in to track your runs
- 📊 **Player Dashboard** - View your High Score and Total Runs at a glance
- 💀 **Game Over Screen** - A "DEFEATED" screen with mission data and options to **RE-INITIALIZE** or **ABORT**

## 🏁 Quick Start

### Play Online
No installation needed! [Launch the live game](https://squaruns.netlify.app/)

### Run Locally

1. Clone the repository:
```bash
git clone https://github.com/kschouhanpali-coder/anti-gravity.git
cd anti-gravity
```

2. Install dependencies:
```bash
npm install
```

3. Start the app:
```bash
npm run dev
```

4. Open the local URL shown in your terminal in your browser

## 🎯 How to Play

1. **Get Ready** - register or log in to track your runs
2. **Launch** - click **PLAY NOW** to start a game
3. **Flip Gravity** - press **`SPACE`** to switch between UP and DOWN and slip through obstacles
4. **Survive** - avoid every platform and stay alive as long as you can
5. **Retry or Abort** - when defeated, choose **RE-INITIALIZE** to play again or **ABORT** to exit
6. **Climb the Ranks** - check the **Leaderboard** and your **Dashboard** for your High Score and Total Runs

> ⌨️ Controls: `SPACE` = invert gravity

## 📊 Game Mechanics

| Element | Description |
|---------|-------------|
| **Gravity** | Toggles between DOWN and UP on each `SPACE` press |
| **Obstacles** | Neon purple platforms spawning from the right |
| **Score** | Increases continuously while you stay alive |
| **Best Score** | Your personal best, tracked across runs |
| **Defeat** | Triggered on collision with any platform |
